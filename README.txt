VEM COMIGO TV - PWA
1. Envie index.html, app.js, sw.js, icon.svg e manifest.webmanifest para a pasta public/ do seu serviço web estático (ou repositório GitHub).
2. Publique via HTTPS (Render Static Site, por exemplo).
3. Abra o site e clique em Importar playlist M3U, selecionando playlist_sp_uruguaiana_porto_alegre.m3u no seu dispositivo.
4. No navegador Chrome, menu > Adicionar à tela inicial / Instalar app.
ATENÇÃO: A playlist não é incluída no site para evitar expor URLs ou credenciais privadas. Reimporte ao recarregar a página. O player depende de links válidos, permissões de acesso, CORS e compatibilidade com HLS ou formato de vídeo.
